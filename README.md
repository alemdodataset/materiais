Planilhas, notebooks e desafios dos vídeos do **Além do Dataset**, o canal de dados e tecnologia para aprender maratonando.

## Como usar

Cada série tem uma pasta, e cada episódio tem a sua dentro dela:

```
dado-muito-prazer/
└── 01-null-nao-e-zero/
    ├── README.md              ← o que tem aqui e o desafio
    ├── pedidos.xlsx / .csv    ← a planilha do episódio
    ├── *.ipynb                ← o notebook (Python)
    └── resposta_desafio.md    ← tenta antes de olhar 😉
```

- **Só planilha?** Baixe o `.xlsx` e abra no Excel, no LibreOffice ou no Google Planilhas.
- **Python?** Abra o notebook no [Google Colab](https://colab.research.google.com) (Arquivo → Enviar notebook) junto com os `.csv`, ou rode no seu computador com `pandas`.
- **Baixar tudo:** botão verde **Code → Download ZIP**.
